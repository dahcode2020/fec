# SEO et contenus publicitaires EMRYS

**Statut :** base éditoriale initiale à valider avant diffusion payante

## Positionnement

EMRYS est un logiciel de gestion modulaire destiné en priorité aux TPE et PME béninoises. Sa promesse est :

> Gestion Sereine

Les messages doivent mettre en avant la simplicité, le contexte béninois, le SYSCOHADA Révisé, le travail hors ligne et la protection des données. Il ne faut pas promettre une conformité fiscale définitive sans validation professionnelle et procédure officielle.

```text

```

### Méta-description

```text
EMRYS accompagne les entreprises béninoises avec la comptabilité SYSCOHADA, la paie, la gestion commerciale, les stocks, le courrier et le travail hors ligne.
```

- logiciel de gestion Bénin ;

Les mots-clés doivent être utilisés naturellement dans les titres, les paragraphes et les pages dédiées. Ils ne doivent pas être répétés artificiellement.

- GCSF : ventes, achats, stocks, facturation et règlements ;
- GC : courriers entrants, sortants, classement et suivi.

## Suivi des campagnes

Les liens publicitaires utiliseront des paramètres UTM cohérents :

```text
utm_source=google
utm_medium=cpc
utm_campaign=emrys-csr-benin
utm_content=annonce-01
```

Sources prévues :

- `google` ;
- `facebook` ;
- `instagram` ;
- `whatsapp` ;
- `tiktok`.

Conversions à suivre :

- ouverture du formulaire d’inscription ;
- inscription à l’essai ;
- demande de démonstration ;
- clic WhatsApp ;
- téléchargement Windows ;
- installation PWA ;
- souscription à une licence.

## Règles avant diffusion

- vérifier la disponibilité et la propriété du domaine ;
- remplacer les coordonnées provisoires si nécessaire ;
- valider les prix et leur traitement HT ;
- ne pas utiliser de faux témoignages ;
- ne pas promettre une homologation non obtenue ;
- obtenir le consentement avant les pixels publicitaires ;
- connecter les formulaires à l’API avant de lancer une campagne payante ;
- faire relire les mentions légales, la confidentialité et les conditions générales.
