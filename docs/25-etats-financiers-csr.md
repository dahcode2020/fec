# États financiers CSR

**Version :** 0.1  
**Statut :** prévisualisation structurée

## Objectif

Présenter les états calculés à partir du périmètre de la société, de la période et du statut sélectionnés.

## États disponibles

- balance générale ;
- compte de résultat ;
- bilan ;
- flux de trésorerie ;
- notes et annexes.

## Modes

- **Contrôle** : écritures validées et écritures en revue ;
- **Officiel** : écritures validées ou clôturées uniquement.

Un état officiel n’est considéré comme définitif qu’après l’arrêté de l’exercice.

## Règles

- le plan comptable de la société active est utilisé ;
- les écritures techniques sont exclues des totaux officiels tant qu’elles n’ont pas été validées dans le traitement prévu ;
- les totaux débit et crédit sont contrôlés ;
- le résultat avant impôt est calculé à partir des comptes de charges et de produits ;
- la période active accompagne l’état ;
- un export conserve le périmètre utilisé.

## Parcours

1. ouvrir **États financiers** ;
2. choisir la période active ;
3. choisir Contrôle ou Officiel ;
4. sélectionner Balance, Compte de résultat, Bilan, Flux ou Notes ;
5. consulter l’aperçu ;
6. exporter ou attendre l’arrêté définitif pour archiver l’état.
